# Calculator-Project
<p>A clean and responsive calculator built using HTML, CSS, and JavaScript. This project performs basic arithmetic operations with a modern dark-themed UI inspired by minimal calculator designs.</p>

<h3>Features</h3>
<ul>
<li>Basic arithmetic operations (+, -, *, /)</li>
<li>Responsive and user-friendly interface</li>
<li>Real-time display updates</li>
<li>Clear button functionality</li>
<li>Stylish dark mode design with circular buttons</li>
<li>Lightweight and beginner-friendly project structure</li>
</ul>

<h3>Tech Stack</h3>
<ul>
<li>HTML5</li>
<li>CSS3</li>
<li>JavaScript (Vanilla JS)</li>
</ul>

<h3>Purpose</h3>
This project was created to practice:
<ul>
<li>DOM manipulation</li>
<li>Event handling in JavaScript</li>
<li>Frontend UI styling</li>
<li>Building interactive web applications</li>
</ul>
